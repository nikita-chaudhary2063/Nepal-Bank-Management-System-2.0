# Nepal Bank Management System 2.0

A menu-driven banking application built with Python using Object-Oriented Programming (OOP), exception handling, and JSON file handling.

## Features
- Manage multiple bank accounts.
- Check account balances.
- Deposit money with input validation.
- Withdraw money with insufficient-balance checks.
- Handle invalid input using `try-except`.
- Save and load account balances using JSON.
- Navigate through interactive account and banking menus.

## Technologies Used
- Python
- Object-Oriented Programming (Classes, Objects, Methods)
- Exception Handling (`try-except-else`)
- File Handling (`open()`)
- JSON (`json.load()` and `json.dump()`)

## Learning Objectives
This project helped me practise OOP, input validation, exception handling, nested loops, and persistent data storage while building a practical banking application.

## Future Improvements

## How to Run
1. Install Python 3.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run:

   `python main.py`

5. Follow the on-screen menu.
